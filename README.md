# Biblioteca escolar · Préstamos

Aplicación web sencilla para registrar préstamos de libros en una biblioteca escolar.

Abre `index.html` en el navegador para usarla. No necesita instalación ni servidor.

Archivos:

- `index.html`: la pantalla.
- `styles.css`: los estilos.
- `prestamos.js`: las reglas del sistema.
- `app.js`: conecta la pantalla con las reglas.
